# 本次修改与维数选择说明

日期：2026-11-03。请求：只使用 PCA 降维，候选维数改为 32、64、96、128，删除额外特征筛选。用户随后明确决定：**选择最高分维度**。当前版本为 `pca-only-highest-cv-2.1`。

## 建议采用的方案

**主实验在调参时同时选择维度；固定参数下的维度比较作为辅助分析。**

对每个模型，32 维调一遍该模型网格，64 维调同一网格，96 维和 128 维同样处理。再比较每维调参后的人员分组 CV 成绩，按事前规则确定维数。

如果先用某一组固定模型参数选出 64 维，然后只在 64 维调参，可能漏掉其他维度在合适参数下的表现。代码执行上某个候选先做 PCA 再训练分类器，与研究设计上“维度和模型参数一起选择”并不矛盾。

| 方案 | 做法 | 本版定位 |
| --- | --- | --- |
| 固定参数比较维度 | 四个维度使用一组事前固定参数 | 辅助分析，保留 |
| 维度与参数联合选择 | 四个维度各自使用同一网格调参 | 正式选模流程 |
| 两套完整策略外部对比 | 每套策略内部选模后，再在共同外部数据上比较 | 本版未新增；仅凭上述 CV 表不能声称完成 |

目前参数网格已包含固定参数候选，因此一次搜索就可以导出两类维度分数，不需要重复两次网格搜索。固定参数集合是项目约定值，不应写成“统一使用 sklearn 默认值”。

## 当前最终维度准则：最高验证分数

每个模型在四个维度分别搜索同一参数网格，选择平均训练人员分组交叉验证 Macro-F1 最高的维度及参数。用原始未四舍五入分数比较，完全同分优先较小维度，再按稳定候选编号决定同维度同分参数。全特征基准独立调参，仅作比较；PCA 即使都低于全特征，仍选择其中最高分方案并保留真实差值。

本次已根据用户明确指令删除上一版的 1 个百分点阈值和最小达标规则。配置显式记录 `pca_selection="highest_cv_macro_f1"`，选模输出记录相同的 `selection_rule` 和 `selection_metric="cv_macro_f1"`。测试集分数、耗时和模型体积不参与维度选择。

- 保留折内拟合、人员隔离、完整 SVD 前缀复用、参数网格和测试前选择锁；选模由最小达标改为最高训练 CV Macro-F1。

- 调整相关软件测试，覆盖折内表示一致性、四维度同网格、最大维度得分最高、精确同分优先小维度、PCA 全部低于 full、旧协议拒绝、断点复用、双联绘图和模型重载。
- README 与现行协议更新；原说明复制到 `docs/legacy_*`，原结果表、图及报告不改写。

## 运行后的阅读顺序

1. `pca_dimension_comparison.csv`：看每个分类器四个维度的固定 / 调参分数和标准差。
2. `selected_configs.csv`：看最终维数、参数、`selection_rule`、`selection_metric` 和相对全特征差值。
3. `test_metrics.csv`：看锁定后的测试表现；不依据此表回头换维数。
4. `PCA_vs_full_with_timing_breakdown.csv`：看压缩后分类、PCA 变换与完整预测耗时的实际变化。

不同模型允许选择不同维数；所有四个维度的结果都会保存，不只保留好看的配置。PCA 累计解释方差是表示的方差保留比例，不是分类准确率，也不能代替人员分组验证分数。

## 本次交付的完成边界

最高分规则的软件回归检查记录在 `validation/pca_highest_cv_20261103/`，上一版检查保留在 `validation/pca_only_20261103/`。本次没有运行正式 HAR 全量网格，也没有验证用户 Windows 机器的实际耗时。旧报告里的数值来自旧协议，必须等待本轮新结果再更新。不能从本次软件检查推断 32、64、96、128 哪个更好。旧最小达标版的断点或结果不能混用为本版运行。
